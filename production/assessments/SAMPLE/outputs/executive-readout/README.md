# SBA Executive Readout Output

This is a test output package for the Small Business Administration DRA. It turns the current SBA Vault wiki into an 11-slide, executive-readable HTML/SPWA readout using the DRAVantage/Kinetic Authority visual direction and the sanitized Werner sample-output patterns.

## Files

| File / Folder | Purpose |
|---|---|
| `deliverable-brief.md` | Audience, thesis, proof objects, visual direction, and constraints |
| `presentation-outline.md` | Slide-by-slide story spine with named visual archetypes |
| `source-notes.md` | Claim-to-evidence ledger for customer isolation and review |
| `open-questions.md` | Gaps caused by draft target-state and roadmap pages |
| `index.html` | Self-contained local HTML staging artifact |
| `qa/` | Mechanical checks and review evidence |

## Build status

- Outline: generated for this test run
- HTML: generated for local preview
- Customer publication: not performed
- Experience Cloud: not yet available; see `../../delivery/experience-cloud/README.md` when the engagement has that placeholder

## Preview

Open `index.html` directly in a browser. It has no external network dependencies and supports arrow keys, Space, Page Up/Page Down, mouse wheel, touch swipe, progress, navigation dots, and reduced-motion preferences.

## Safety boundary

This package uses only evidence from `assessments/SBA/`. The Werner sample-output reference supplies visual structure only; it is not used as a source of customer claims, metrics, logos, images, or personal information.
