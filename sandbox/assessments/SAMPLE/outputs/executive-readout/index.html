SBA / sequence10 / 11

Draft roadmap

Unlock first. Trust in parallel. Activate with proof.

Draft sequence

The final timing, owners, dependencies, and success measures require sponsor and system-owner confirmation.

1

Crawl

Unlock the foundation
  • Choose one high-value manual loop.
  • Define identity and source boundaries.
  • Extend API coverage from the existing integration foundation.
2

Walk

Strengthen Trust
  • Add matching, quality, lineage, consent, and IAM controls.
  • Make documentation requirements enforceable.
  • Validate cross-program context with owners.
3

Run

Activate responsibly
  • Expand proactive outreach and risk signals.
  • Embed decisions in staff and contact-center workflows.
  • Scale agents where guardrails are proven.

Trust is a parallel design responsibility—not a gate postponed until after every integration.
