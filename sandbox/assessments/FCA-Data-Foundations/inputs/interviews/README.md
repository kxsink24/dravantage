# Interviews

One structured note per completed interview, created by `dra-analyze-input` when a transcript is processed.

## File naming

`YYYY-MM-DD-<stakeholder-lastname>.md`

## Per-interview note structure

Each file contains:

- **Frontmatter:** date, stakeholder name, title, module, interview status, recording URL, transcript URL
- **Key quotes:** verbatim quotes organized by DRA theme (barriers, capabilities, magic wand)
- **Extracted insights:** what this interview added to the assessment, cross-referenced to wiki pages updated
- **Capability signals:** which Data Value Chain capabilities were discussed and what the signals suggest about the score
- **Knowledge gaps:** what this interview didn't cover that was expected, or what new questions it opened

## Module mapping

| Module | Persona | Primary topics |
|---|---|---|
| Module 1 | People Leader | Strategic priorities, sponsorship, magic wand, compelling event |
| Module 2 | Business User | Day-in-the-life pain, data access, trust in data, desired outcomes |
| Module 3 | IT / Data Scientist | System inventory, integration architecture, data quality, governance |
