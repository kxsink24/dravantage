# Setup

Pre-kickoff artifacts generated by `dra-kickoff`. These are working materials — not customer-facing deliverables. The survey and email templates will be adapted for actual sending; the kickoff deck draft will be refined before delivery.

| File | What it is | Created by |
|---|---|---|
| `survey-draft.md` | Tailored DRA survey with per-question customization and interpretation notes | `dra-kickoff` |
| `email-templates.md` | Kickoff invitation, survey distribution, and interview confirmation email drafts | `dra-kickoff` |
| `kickoff-deck-draft.md` | Customer-specific kickoff presentation draft | `dra-kickoff` |

Files in this folder are inputs to the engagement — they inform how the kickoff is run and how the survey is distributed. They are not analyzed by `dra-analyze-input`.
