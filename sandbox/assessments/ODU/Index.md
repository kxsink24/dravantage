## Key Findings (running summary)

> [!NOTE]
> `dra-analyze-input` updates this section after each analysis run. Do not edit manually.

**Three Barriers:**
- Blind Spot: **High** — 3 disconnected Salesforce orgs + Banner + LMS; no unified Student 360
- Time Trap: **High** — batch Banner→Salesforce data; sub-second API gap on the Monarch portal
- Trust Gap: **Medium** — analytic data inconsistencies; no catalog / MDM

**Scores:** Integration Health: 33 / 100 · AI Readiness: 33 / 100 *(provisional — pre-discovery)*

**Personas (run 2, kickoff-only, Low confidence):** Business Leader, IT Leader, IT Worker, and Data Leader (Data & Analytics sub-type) synthesized from the 5/11 session. **Business Worker and Data Worker are unrepresented** — a Module 2 enrollment/advising interview is the top coverage gap before the readout, since the POC agent is built for that persona.

**Narrative thread:** ODU has committed to a "Salesforce First" One Monarch Nation, but authoritative student data lives in Banner and moves in batches — so the flagship "what's the status of my application?" agent can't be built on today's foundation. The pattern is a classic **Crawl** (API-led + real-time integration foundation) with **shadow AI ambition** running ahead of an Unlock score of 1 (GIGO risk): fix Unlock + Trust before activating agents.
